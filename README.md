### Featured work

#### [Out-of-Order 4-Issue Superscalar Processor based on LoongArch](https://gitee.com/yan098/nscscc-nputeam/tree/master/NSCSCC2026/nscscc-team1)
`LoongArch` `Verilog RTL` `Vivado` `Computer Architecture` `Hardware Debugging`

* Designed and verified an out-of-order 4-issue superscalar CPU supporting 8-way fetch, 4-way decode, in-order commit, register renaming, branch prediction, and partial out-of-order Load execution.
* Responsible for MMU and TLB design, memory pipeline supporting partial out-of-order load execution, multi-port issue queue, and an 8-to-4 InstFIFO buffer.
* Achieved **80 MHz** operating frequency with an IPC of **1.518×** compared to openla500; awarded **National Second Prize** in the 2026 Loongson Cup.

#### FCGP: Function-Conditioned Graph Retrieval for Functional 3D Grounding
`3D Grounding` `Graph Retrieval (GNN)` `Embodied AI` `Python` `Robotics`

* Developed a query-conditioned edge-gated graph retrieval framework for natural-language-driven functional 3D grounding, evaluated and demonstrated on the Unitree G1 humanoid robot.
* Built automated data filtering and verification pipelines in Python to rectify annotations, extract geometric spatial properties (position, scale), and enhance multi-step relational reasoning benchmarks.
* *(Targeted for submission to IEEE RAL)*
